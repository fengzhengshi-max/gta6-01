Neon Palms is a 2D top-down open-world crime game set in a neon-lit coastal city: explore on foot or by stolen car, dodge traffic and pedestrians, earn wanted stars and outrun the police, fight rival gangs, and run five story jobs for Mara, the bar owner — with a HUD, a live minimap, synthesized sound and autosaving. The whole game is plain static files (game/index.html plus ES modules): no libraries, no network requests, playable offline in any desktop browser.

## Run it

```sh
node serve.ts # serves game/ on http://localhost:8080 — open it in a desktop browser
```
